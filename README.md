## Featured Projects

### 1. CSE 031 - Lab 1: Introduction to C

### 2. CSE 031 - Lab 2: GDB and Pointers
This project explores GDB debugging techniques, array copying procedures, pointer manipulation, and memory-safe program structures in C.

For a complete architectural breakdown, structural component analysis, and sanitized code walkthroughs, view the **[CSE 031: Lab 2 - GDB and Pointers](https://github.com/vdeleon-chavarria/VDL-portfolio/wiki/CSE-031:-Lab-2-%E2%80%90-GDB-and-Pointers)** wiki page.

### 3. CSE 031 - Lab 3: Memory in C
This project explores dynamic memory allocation, array manipulation, struct definition, and linked list operations in C. The goal of this lab is to deepen my understanding of heap-allocated memory, custom node structures, and recursive data structures such as linked lists.

For a complete architectural breakdown, structural component analysis, and sanitized code walkthroughs, view the **[CSE 031: Lab 3 - Memory in C](https://github.com/vdeleon-chavarria/VDL-portfolio/wiki/CSE-031:-Lab-3-%E2%80%90-Memory-in-C)** wiki page.

### 4. CSE 031 - Lab 4: More Memory in C
This project explores multidimensional arrays, dynamic memory allocation for 2D structures, matrix multiplication algorithms, and memory casting in C. The goal of this lab is to understand how contiguous memory blocks represent multi-dimensional matrices and how to manage data type casting safely.

For a complete architectural breakdown, structural component analysis, and sanitized code walkthroughs, view the **[CSE 031: Lab 4 - More Memory in C](https://github.com/vdeleon-chavarria/VDL-portfolio/wiki/CSE-031:-Lab-4-%E2%80%90-More-Memory-in-C)** wiki page.

### 5. CSE 031 - Lab 5: Intro to MIPS
This project explores MIPS assembly language programming, register management, arithmetic operations, and execution workflows using the MARS MIPS simulator. The goal of this lab is to understand low-level instruction sets, branching control flow, and iterative sequence generation in assembly.

For a complete architectural breakdown, structural component analysis, and sanitized code walkthroughs, view the **[CSE 031: Lab 5 - Intro to MIPS](https://github.com/vdeleon-chavarria/VDL-portfolio/wiki/CSE-031:-Lab-5-%E2%80%90-Into-to-MIPS)** wiki page.
